# lane-stack (Claude Code plugin)

> 한국어판은 claude-code-mods-ko 프로젝트가 번역했습니다. 원작자와 라이선스는 문서 끝에 있으며, 영어 원문은 [README.en.md](README.en.md)에서 볼 수 있습니다.

1인 PM용 컨베이어입니다. 오케스트레이터 에이전트, 레인별 작업 지침, 온보딩과 재개 명령을 제공합니다.

## 설치

```
/plugin install lane-stack@claude-code-mods-ko
```
