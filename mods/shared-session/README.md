# shared-session

> 한국어판은 claude-code-mods-ko 프로젝트가 번역했습니다. 원작자와 라이선스는 문서 끝에 있으며, 원문 README가 없어 플러그인 설명을 기준으로 작성했습니다.

링크나 팀으로 Claude Code 세션을 공유합니다. 팀원이 각자의 Claude Code에서 참여해 대화할 수 있습니다. 한 세션이 작업을 수행하고 모두가 모든 턴을 실시간으로 보며, 호스트가 자기 컴퓨터에서 실행되는 항목을 승인합니다. 팀은 GitHub 또는 Google로 로그인해 팀의 실시간 세션을 보고 한 번의 누름으로 참여할 수 있습니다. 직접 서버를 설정하지 않으면 공유는 이 프로젝트의 공개 서버를 거칩니다(개인정보 및 공개 서버는 README 참조).

## 설치

```
/plugin marketplace add claude-code-mods/claude-code-mods-ko
/plugin install shared-session@claude-code-mods-ko
```
