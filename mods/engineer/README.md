# engineer

> 한국어판은 claude-code-mods-ko 프로젝트가 번역했습니다. 원작자와 라이선스는 문서 끝에 있으며, 원문 README가 없어 플러그인 설명을 기준으로 작성했습니다.

Disciplined Agentic Engineering(DAE) — Claude Code용 방법론 키트입니다. 기능 접수, 인수 조건 탐색, 명세 작성, 계획, 구현, 검증, 강화의 DAE 파이프라인을 구현하는 스킬을 제공합니다.

## 설치

```
/plugin marketplace add claude-code-mods/claude-code-mods-ko
/plugin install engineer@claude-code-mods-ko
```
