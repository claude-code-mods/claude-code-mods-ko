# lcu-approve

> 한국어판은 claude-code-mods-ko 프로젝트가 번역했습니다. 원작자와 라이선스는 문서 끝에 있으며, 원문 README가 없어 플러그인 설명을 기준으로 작성했습니다.

Claude 앱과 Claude Code에서 LCU 컴퓨터 사용을 앱별로 기본 승인합니다(이 대화만 허용, 항상 허용, 거부). 승인된 앱 목록은 /computer-use-apps 패널에서 볼 수 있습니다.

## 설치

```
/plugin marketplace add claude-code-mods/claude-code-mods-ko
/plugin install lcu-approve@claude-code-mods-ko
```
